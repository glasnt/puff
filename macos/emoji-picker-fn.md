# MacOS Emoji Picker

Originally, you had to use <kbd>Control</kbd> + <kbd>Command</kbd> + <kbd>Space</kbd> to get to the emoji picker. 

TIL as of [Big Sur](https://support.apple.com/en-mk/guide/mac-help/mchlp1560/11.0/mac/11.0), you can just use the <kbd>Fn</kbd> key. 

Given so many systems use OS-agnostic selection systems -- either a WYSIWYG button of `:`-based picking -- knowing there's an
simpler option for my particular OS is delightful.

(Your usage of emoji in various applications and them _being accepted_ is left to the reader.)
