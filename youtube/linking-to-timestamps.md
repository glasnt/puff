# Linking to YouTube Timestamps

_This information may atrophy over time as the YouTube UI changes_

If you want to link to a specific point in time in a YouTube Video, you can right-click the video mid-playing, and select "Copy video URL at current time". 

If you have a video with many segments that would be useful to have chapter markings (e.g. a conference lightning talk video), you can use timestamps in the description ([Video Chapters](https://support.google.com/youtube/answer/9884579?hl=en), YouTube support.), which will create chapters in the video. This will also help with searchability of content.
