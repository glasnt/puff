# Export Google Docs as Markdown

One of the features that I like from smaller rich browser editors over the years
has been the ability to write Markdown and have the styling automatically apply.

This has been an option in [Google Docs since 2022](https://workspaceupdates.googleblog.com/2022/03/compose-with-markdown-in-google-docs-on.html).

Now, I've learnt that you can use `File > Download` to export a [Google Doc as markdown](https://workspaceupdates.googleblog.com/2024/07/import-and-export-markdown-in-google-docs.html).

I've previously used the [Docs to Markdown](https://workspace.google.com/marketplace/app/docs_to_markdown/700168918607) extension, but this functionality is now available by default in Docs.
