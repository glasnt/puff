# Paste from markdown

Not only can you [export as Markdown](https://glasnt.com/puff/google_workspace/url_tricks), you can now paste from Markdown in docs!

This is extremely useful to have automatic formatting from input that, if entered manually, would be automatically formatted. 

This is also useful for exporting from generated markdown content into docs for reusability. 

[Use Markdown in Google Docs, Slides, & Drawings](https://support.google.com/docs/answer/12014036?hl=en)
